# Kiki eSIM — ALL content, not just the app screens

This is the complete body of work, in two parts. Both live on the same domain.

## Part 1 — the 78 curated app screens

The reviewed app screens, ids **S001 to S078**, with annotated overlays and
coordinate bands. They are the thing to open when Balraj is talking about how
the app looks or behaves.

    Index for an assistant : https://balraj1604.github.io/kiki-esim-screens/FOR-AI.md
    Human gallery          : https://balraj1604.github.io/kiki-esim-screens/

## Part 2 — everything else (4605 files)

Every other file Balraj dropped: the Emirates illustration library, wallpapers,
boarding-pass art, destination city assets, the globe/widget assets, the app
screen library export, the animation source files, the generation specs and
route timetables, and the full session transcripts.

These carry **D numbers**, D0001 to D4605. When Balraj says "D412" or
"drop 412", open item 412. The authoritative flat list is:

    SEE THEM ALL, one page : https://balraj1604.github.io/kiki-esim-screens/all.html
    Plain text, every item : https://balraj1604.github.io/kikiesim/manifest.txt
    JSON                   : https://balraj1604.github.io/kikiesim/manifest.json
    TSV, all fields        : https://balraj1604.github.io/kiki-esim-screens/catalog/all.tsv
    Compact JSON           : https://balraj1604.github.io/kiki-esim-screens/catalog/all.json

Deep link straight to an item: https://balraj1604.github.io/kiki-esim-screens/all.html#D0412

## Addressing — do not mix the two

    S007  or "screen 7"  -> curated app screen 7      (Part 1)
    D0412 or "drop 412"  -> dropped asset 412         (Part 2)

If a bare number is ambiguous, ask which part he means before answering.
